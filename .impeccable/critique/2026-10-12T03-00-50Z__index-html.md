## Priority Issues

[P1] Card de troca pisca a cada troca de rotina. `#wait`/`.wait-card` aparece na hora com véu, texto denso e contagem "60 s", mesmo quando a parada leva 1 s. Fix: revelar o card só depois de ~750ms (timer em renderWait ou visibility com atraso), foco no card quando aparecer; reduzir movimento mantém. Comando: /impeccable animate + harden.

[P2] Zona de ações do cabeçalho sem divisão e contraditória durante a troca. `:3333`, "Parar API", "Parar tudo" e "Parou em" são texto 13px ink-2 numa corrida só; durante AGUARDA viram "Subir API / Subir tudo". Fix: esconder halt-tab/halt-all enquanto stopping.has(project); fio rule entre abas+porta e ações; recado separado das ações. Comando: /impeccable layout + clarify.

[P2] Âmbar demais e colisão PAR-. SUBINDO, AGUARDA, PARANDO e ENCERRA em âmbar; PARCIAL (vermelho) e PARANDO (âmbar) começam com PAR, par fraco para deutan/protan. Fix: ENCERRA como prévia sem as metades da palheta; renomear PARCIAL (ex.: "1 LADO", "CAÍDA"). Comando: /impeccable clarify.

[P2] Encaixe vazio lê como pontuação. Na paleta o entalhe esquerdo cola no projeto ("INTERNO –"); no painel, 9 linhas de "–  –"; no estado vazio o encaixe desloca (sem coluna do lápis). Fix: tirar o encaixe da paleta; no painel, mais apagado ou só no hover/foco; alinhar o fantasma. Comando: /impeccable quieter + polish.

[P3] Frase do card difícil de ler. "Ctrl+C enviado a npm run dev. auth-refresh feat/ ⇄ feature/ sobe quando…": começa com branch minúscula, prefixos do par na prosa. Fix: "Ctrl+C enviado a npm run dev. Quando as portas liberarem, sobe auth-refresh." (só o nome; rótulo completo no title). Comando: /impeccable clarify.
