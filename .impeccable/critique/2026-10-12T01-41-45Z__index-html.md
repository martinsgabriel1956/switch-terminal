Deterministic scan: CLI `index.html` 2 findings (design-system-color rgb(0,0,0) on h1, flat-type-hierarchy), both false positives because CSS is imported from main.ts and the static scan saw browser defaults. `src` clean. ## Overall Impression

A mature, principled Operate surface; the destructive moment is the best-designed part. The weakest link is the header note: one shared slot that is cross-project, loses its context, and can overwrite the journey's ending.

## What's Working

1. ENCERRA preview: the consequence appears in place before the click, with the same word on board, palette footer and "Abrir ao criar", deliberately not PARANDO.
2. Switch card ergonomics: focus on the group, Voltar before Forçar, Esc unbound, names the real process (`npm run dev`) and counts down to SIGKILL.
3. Data-specific rendering: prefix-only divergent pairs collapse to one name + prefixes; prefixes drop per platform; long names truncate at the end, never as an abbreviated prefix.

## Priority Issues

**[P1] Header note loses project and overwrites the switch closure.** `pollStatus` builds the 15 s note with `labelNodes(wt.label)` only (src/main.ts:1154), while `announceDrops` includes `env.project` (src/main.ts:1131). Result: "Front não subiu em 15 s · main" while on INTERNO, which also has a main; and any `headerNote` replaces "Parou em 1,8 s · feat/x". Fix: always include the project when the note is not about `current`; don't let a cross-project note overwrite a closure younger than 8 s (append with " · " or queue); optionally mark the failure on the affected platform plate. Command: /impeccable harden + /impeccable clarify.

**[P1] Narrow layout drops the branch entirely.** At 600px (sidebar overlay, header ≥480px) the destination shows `INT… /` then the flap; the branch is gone while `#last-stop` keeps its `minWidth` from `headerNote` (src/main.ts:147). Contradicts DESIGN.md ("the note cedes width first"). Fix: drop the note's min-width when the branch would truncate, or hide `#last-stop` in narrow. Command: /impeccable adapt.

**[P2] Stop / stop-all / start icons are ambiguous.** Stroked 7×7 square and pair of squares read as maximize/checkbox; label only in `title`. Fix: filled stop glyph (explicit exception to the no-fill rule) or caps text buttons PARAR / PARAR TUDO / SUBIR. Command: /impeccable clarify.

**[P2] Never-opened slot reads as an empty input and dominates the status column.** `.flap[data-state="none"]` inset 1px rule box is the most repeated shape on the board and in the palette. Fix: quieter encaixe (just the two seam notches, or a 1px baseline the slot width). Command: /impeccable quieter.

**[P2] New-project dialog hides its primary action and asks too much at once.** At 1440×900 "Criar projeto" is below the fold of the 84vh scroll; each side shows Repositório and "Ou clone do GitHub" together (~14 controls). Fix: sticky `dialog.form menu`; per side a two-choice "Pasta local | Clonar do GitHub" revealing one path. Command: /impeccable distill (+ layout).

## Persona Red Flags

**Alex (power user):** Tab from a board line goes to the next platform's fold/+; current platform's controls need Shift+Tab. No project jump. Palette lists everything flat in full ink, so live items don't stand out.

**Sam (keyboard / SR / low vision):** SR work is unusually good (spoken states, aria-description for ENCERRA, silent destination during a switch). Branch vanishes in the narrow/zoomed header. Disabled `+`/pencil in ink-3 (3.95:1) vs enabled ink-2 (7:1) look nearly the same at 16px. Flap text 12px.

**O autor alternando o dia todo:** closure lost whenever another project emits a note; a leilao failure lands in the INTERNO header as "· main"; hover vs current row (`--hover` vs `flap`) close in dark; seven empty slots per glance.
